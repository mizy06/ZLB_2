# 机器学习基础

机器学习是人工智能的一个分支，它通过数据和算法使计算机系统改善任务表现。

## 监督学习

监督学习是指使用带标签的数据训练模型的方法。监督学习包括分类和回归。

分类用于预测离散类别，例如识别邮件是否为垃圾邮件。回归用于预测连续数值，例如估计房屋价格。

## 模型训练

损失函数用于衡量模型预测与真实结果之间的差异。优化算法用于最小化损失函数。

梯度下降是一种常用的优化算法。学习率决定梯度下降每一步更新参数的幅度。学习率过大会导致训练不稳定，学习率过小会导致收敛缓慢。

## 泛化能力

过拟合是指模型在训练数据上表现良好，但在新数据上表现较差的现象。正则化用于降低过拟合风险。

训练集用于学习模型参数，验证集用于选择超参数，测试集用于评估最终模型。
