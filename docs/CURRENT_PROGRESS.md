## 百炼 CLI 调研

本机验证版本：

```text
bailian-cli 1.7.0
```

当前官方 CLI 支持：

- `bl app list`
- `bl app call`
- `bl pipeline validate`
- `bl pipeline run`
- `bl console call`

当前没有公开的低代码作者态命令：

- 工作流创建。
- 工作流画布编辑。
- 工作流 DSL 导入或导出。
- 工作流发布。

`bl pipeline` 是 CLI 本地 Pipeline 执行器，不会创建百炼控制台中的低代码应用。因此当前最稳妥的方式是：控制台负责创建、导入、导出和发布，CLI 负责应用查询、调用和验收。
